These files are a held-out writing evaluation constructed on 2026-11-10 from four primary papers, one from each requested venue. The selection deliberately includes different contribution types: sparse accelerator, workload analysis with a persistence mechanism, deployed-system evaluation, and analytical design-space tooling. It is a small purposive set, not a representative sample of all architecture writing.

The source papers and extracted fulltexts were read by the case constructor only. Development-corpus papers, annotations, rules, and the user's research design were not consulted to construct these cases. The supplied exclusion list was used only to avoid selecting those papers. No claim is made that these public papers were absent from model pretraining. The writer task measures drafting from independently assembled factual briefs, not unseen-paper memorization resistance.

Only `writer-briefs.json` should be delivered to a writer, one case independently per run. It omits source title, source URL, recognition, source locators, expected fact IDs, and the grading targets. Author terminology and real prior-work metadata remain, so this is identity-reduced rather than anonymous. `heldout-cases.json`, `heldout-key.json`, and this note are evaluation-only and must be excluded from retrieval and rule development. The key gives evidence/coverage criteria, not an intended answer, sentence template, or original abstract/introduction analysis.

Validation parsed all three JSON files, checked four-venue balance, two references per case, case/ID correspondence, numeric locators, coverage weights totaling 35, overall rubric weights totaling 100, and the absence of grader/source fields from writer inputs. An eight-word consecutive-overlap scan of factual-brief prose against extracted source text found no matches; bibliographic metadata and necessary technical names were excluded. No source-prose quotations were intentionally used. This mechanical check is not a plagiarism or novelty guarantee.

The final key also defines eight stable metric IDs, weighted to 100, with explicit capped per-metric penalties and a reproducible summation contract. Coverage is weighted within fact fidelity; missing facts are not treated as fabrications. Penalties require quoted output evidence, repeated claims count once, and one underlying error receives its most specific rule only. Fabricated central scientific content is flagged separately. No pass threshold was selected from these held-out outcomes.
